## Establish what is fixed

Start from an approved plan, model view, or perspective. State which paths, structures, tree locations, and materials should remain unchanged. Keep a copy of the source image for comparison.

## Review the output systematically

Compare the generated view with the drawing: count entrances, check path connections, look for altered grades, and inspect plants and built elements. Mark uncertain details before using the image in a presentation.

## Caption honestly

Identify an image as a conceptual visualization when it does not depict a resolved design. For technical decisions, show the plan or section that supports the view. Visual quality is useful only when the image still communicates the actual proposal.
